## Data Field Mappings in PDF

### Organization List Table (Section C)
```
Column 1: org.name             → "Organization Name"
Column 2: org.domain           → "Domain"
Column 3: org.plan             → "Tier"
Column 4: org.status           → "Status"
Column 5: org.users            → "Employees" (or 0 if missing)
Column 6: org.created          → "Registered" (formatted: DD MMM YYYY)
Column 7: org.adminEmail       → "Root Admin"
```

### Recently Registered (Section D)
```
Column 1: org.name             → "Organization Name"
Column 2: org.plan             → "Tier"
Column 3: org.users            → "Total Users"
Column 4: org.created          → "Registration Date" (formatted: DD MMM YYYY)
Column 5: org.status           → "Status"
```

### Subscription Overview (Section E)
```
Column 1: sub.organizationName → "Organization Name"
Column 2: sub.planName         → "Current Plan"
Column 3: sub.startDate        → "Plan Start Date" (formatted: DD MMM YYYY)
Column 4: sub.expiryDate       → "Plan Expiry Date" (formatted: DD MMM YYYY)
Column 5: sub.billingCycle     → "Billing Cycle"
Column 6: sub.status           → "Status"
```

## Chart Embedding Process

```
1. Chart refs passed to PDF generator
   ↓
2. For each chart ref:
   ├─ Check if DOM element exists
   ├─ Use html2canvas to capture PNG
   │  └─ Scale: 2x (high DPI)
   │  └─ Background: White
   │  └─ CORS: Enabled
   ├─ Convert to base64 data URL
   └─ Return PNG data
   ↓
3. In PDF generation:
   ├─ Draw container with border and padding
   ├─ Add chart title above container
   ├─ Check if page space available
   ├─ Add page break if needed
   ├─ Insert image with addImage()
   └─ Update Y position for next content
```
