## 🔍 Known Limitations & Notes

1. **Chart Embedding**: Charts require explicit refs to be passed. If refs not provided, PDF generates without charts.
2. **Large Datasets**: Very large datasets (5000+ organizations) may take longer to generate.
3. **Browser Dependent**: PDF generation requires browser with html2canvas support.
4. **Same-Origin Policy**: Chart capture may fail if charts use external images (CORS).
5. **File Size**: PDFs with many charts can be larger (5-20MB possible).
